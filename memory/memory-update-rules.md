# Memory Update Rules

Version: V1.0


# 一、Memory作用

Memory用于保存长期有效的信息。

目的：

让AI助理持续理解用户目标、
工作方式和发展方向。


---

# 二、Memory分类


## 1. Personal Memory（个人信息）


保存：

- 长期职业方向
- 学习方向
- 工作习惯
- 输出偏好


例如：

用户关注银发体育健康方向。


---

## 2. Work Memory（工作记忆）


保存：

- 当前工作任务
- 项目进度
- 工作方法


例如：

正在建设个人AI助理系统。


---

## 3. Knowledge Memory（知识记忆）


保存：

- 行业知识
- 学习成果
- 方法论


例如：

银发经济研究内容。


---

# 三、信息保存规则


需要保存：

长期有效

+

未来会重复使用

+

能够提升AI服务质量


---

不保存：

一次性任务

临时聊天内容

短期无价值信息


---

# 四、Memory更新流程


用户输入

↓

判断信息价值

↓

分类Memory

↓

更新知识库

↓

后续调用


---
