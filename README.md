# Personal AI Assistant

## 项目介绍

这是一个基于 GitHub 管理的个人 AI 助理系统。

通过知识库、技能模块、提示词系统、工作流和用户记忆模块，实现个人工作效率提升和知识管理。


## 核心目标

打造属于个人的 AI 工作伙伴，帮助完成：

- 工作日志生成
- 学习资料整理
- 行业研究分析
- 项目方案优化
- 信息管理


## 当前能力模块


### 1. Knowledge Base（知识库）

用于沉淀专业知识。

当前方向：

- 银发体育健康
- 体育健康养老
- 运动干预
- OPC项目研究


### 2. Skills（技能模块）

包含：

- 日志助手
- 会议助手
- 研究助手
- 银发体育健康研究助手


### 3. Prompts（提示词系统）

用于管理 AI 调用规则。

包含：

- 系统提示词
- 工作提示词
- 任务路由规则


### 4. Workflows（工作流）

用于管理重复工作流程。

当前：

- 日常复盘流程


### 5. Memory（用户记忆）

记录：

- 用户基础信息
- 工作方向
- 学习目标
- 输出习惯
