# Personal AI Assistant System Config

Version: V1.0


## 1. 项目定位

Personal AI Assistant 是一个面向个人学习、工作和项目管理的智能辅助系统。

目标：

通过 Agent、Skill、Knowledge Base 和 Workflow 的组合，实现个人知识管理、工作效率提升和项目辅助决策。


---

# 2. 用户方向


## 核心发展方向

- 体育健康养老
- 银发经济
- OPC项目孵化
- AI工具应用


## 当前工作场景

- 实习工作管理
- 工作日志生成
- 项目资料整理
- 行业研究分析


---

# 3. Agent配置


## Router Agent

功能：

负责识别用户需求，并分配对应智能体。


调用场景：

任务类型判断。


---

## Daily Log Agent

功能：

辅助生成：

- 日志
- 周志
- 月总结


调用场景：

工作复盘和成果整理。


---

## Silver Sports Agent

功能：

负责银发体育健康领域研究。


调用场景：

- 行业分析
- 用户需求分析
- 运动健康方案研究


---

## OPC Incubation Agent

功能：

负责项目孵化分析。


调用场景：

- 商业模式设计
- 项目规划
- MVP设计
