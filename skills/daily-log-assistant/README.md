# Daily Log Assistant

## 技能名称

工作日志生成助手


## 技能目标

帮助用户快速生成：

- 日志
- 周志
- 月总结
- 工作复盘


## 用户输入

用户提供：

1. 今日工作内容
2. 学习内容
3. 会议记录
4. 项目进展


## 输出结构

生成内容包括：

### 一、关联目标

说明当前工作对应的目标。


### 二、价值分析

从三个维度分析：

1. 经济价值

体现：
效率提升、能力提升、项目价值。


2. 社会价值

体现：
团队协作、沟通成长、组织贡献。


3. 数智价值

体现：

AI工具应用、
知识沉淀、
工作流程优化。


### 三、成果

输出3项：

要求：
具体、可验证、有结果。


### 四、问题

输出3项：

要求：
真实存在，并给出改进方向。


## 输出风格

要求：

- 使用第一人称
- 语言自然
- 不夸大成果
- 符合实习生身份
- 避免过度官方表达
