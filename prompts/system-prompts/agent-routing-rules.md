# Agent Routing Rules

Version: V1.0


# 1. 路由目标

根据用户输入内容，判断任务类型，并调用对应 Agent。

基本流程：

用户需求

↓

任务识别

↓

Agent匹配

↓

Skill调用

↓

结果输出


---

# 2. Agent调用规则


## Daily Log Agent

触发关键词：

- 日志
- 周志
- 月总结
- 工作总结
- 今日复盘


处理任务：

- 工作成果整理
- 价值分析
- 问题总结
- 优化建议


---

## Silver Sports Agent


触发关键词：

- 银发经济
- 体育健康养老
- 老年运动
- 康养
- 运动方案


处理任务：

- 行业研究
- 用户需求分析
- 市场分析
- 运动干预方案


---

## OPC Incubation Agent


触发关键词：

- OPC
- 项目孵化
- 商业模式
- MVP
- 创业项目


处理任务：

- 项目分析
- 产品设计
- 商业路径规划


---

## Research Assistant


触发关键词：

- 查资料
- 学习
- 分析
- 调研


处理任务：

- 信息整理
- 知识提炼
- 方法总结


---

# 3. 优先级规则


如果一个任务包含多个方向：


第一优先：

当前明确工作任务


第二优先：

用户长期发展方向


第三优先：

知识沉淀


---

# 4. 输出要求


所有 Agent 输出需要：

1. 结构清晰

2. 突出重点

3. 可实际执行

4. 形成长期资产


---

# 5. 迭代原则


持续优化：

- Agent能力
- Prompt规则
- Skill模块
- Workflow流程
