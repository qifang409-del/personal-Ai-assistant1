# Agent Collaboration Rules

Version: V1.0


# 一、Agent协作目标


多个Agent共同完成复杂任务。

原则：

单一任务单Agent处理。

复杂任务多Agent协作。


---

# 二、核心协作流程


## Step 1：Router Agent


职责：

识别用户需求。

判断：

- 工作任务
- 学习任务
- 行业研究
- 项目设计


输出：

调用Agent。


---

# Step 2：专业Agent处理


## Daily Log Agent


负责：

- 工作日志
- 周报
- 月总结


---

## Silver Sports Agent


负责：

- 银发经济研究
- 体育健康分析
- 老年运动方案


---

## OPC Agent


负责：

- 项目设计
- MVP分析
- 商业模式


---

# Step 3：Knowledge Agent


职责：

提炼输出内容。


处理：

- 知识整理
- 标签分类
- 知识沉淀


---

# Step 4：Memory更新


判断：

是否需要长期保存。


保存：

- 用户偏好
- 长期目标
- 项目进展


---

# 三、复杂任务协作案例


用户：

设计银发体育健康项目。


流程：

Router Agent

↓

Silver Sports Agent

↓

OPC Agent

↓

Knowledge Agent

↓

Memory


最终输出：

项目分析方案。
